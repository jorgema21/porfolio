Para analizar la evolución de los galardonados y nominados en los Premios Óscar, desarrollé un sitio web desde cero combinando diseño, narrativa, desarrollo y visualización de datos. Con Visual Studio Code, Svelte y Google Sheets procesé el histórico de películas nominadas y premiadas para crear gráficos personalizados sin limitaciones técnicas.

Este fue mi primer proyecto con Svelte. Diseñé la web con una paleta en tonos dorados inspirada en las estatuillas, combinada con grises y negros. Creé una portada con Adobe Illustrator y Photoshop usando imágenes de Wikipedia. Desarrollé un scrollytelling donde las tarjetas simulaban claquetas de cine con años clave. Las imágenes de fondo cambiaban según el dispositivo.

Parte de scrollytelling del proyecto

Después, diseñé un mapa de calor tipo calendario para visualizar los años con más premios. Añadí tooltips con información por año y una escala de color por niveles.

Distribución de estatuillas por año

A continuación, desarrollé un scatterplot con todas las películas nominadas del certamen. Con más de 5.000 registros, apliqué jitter para evitar solapamiento de puntos. Esto permitió visualizar mejor la densidad de premios y nominaciones.

Añadí un checkbox para aislar nominados de 2025 y atenuar el resto y filtros por categorías y tooltips con información detallada.

Relación entre premios y nominaciones

Para facilitar la exploración, creé una tabla con buscador y ordenación múltiple. Añadí barras visuales dentro de las celdas para enriquecer la lectura de datos.

Tabla de datos explorables

Como cierre, añadí un mapa coroplético de países según su éxito en Mejor Película Internacional. Dupliqué la lógica de búsqueda y añadí un sistema de pestañas para alternar vistas.

Mapa global de resultados

Este proyecto fue mi primera gran inmersión en Svelte sin SvelteKit. Aunque ya entendía conceptos HTML, CSS y JavaScript, el reto fue crear visualizaciones complejas. Trabajé con datos estructurados que limpié y procesé manualmente. El uso de IA me ayudó a acelerar el aprendizaje y la implementación. Este proyecto consolidó mi base para futuros desarrollos más eficientes.
